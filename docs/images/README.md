## Recapture / 复拍

Use a clean browser profile, open the source URL, set the viewport, select Appearance → Dark (外观 → 深色), and follow the relevant guide section. Use only placeholder connection details and the public reference asset. Capture the real drawer or composer after controls settle; do not inject mock results or rewrite interface labels. Update both guides' captions and this capture date when replacing images.

使用干净的浏览器配置打开来源地址，设置视口，在「外观」中选择「深色」，按教程对应章节操作。只使用占位连接信息和公开参考图。控件稳定后截取真实抽屉或输入区，不注入模拟结果、不修改界面标签。更换截图时同步更新两份教程的图注与此处日期。
