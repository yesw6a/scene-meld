## 1. 使用前准备

![SceneMeld 实际工作区：左侧会话列表、右上连接状态、中间配置连接入口、底部提示词输入区](./images/workspace.png)

*图 1：首次打开的实际工作区。点击中间「配置连接」或右上「未配置」进入设置；底部为创作输入区。*

你需要从所选 API 服务提供商处获得：

- **API 基础地址（Endpoint）**：图片请求的目标服务地址。
- **API Key**：有权调用该服务生图模型的密钥。
- **可用模型 ID**：服务支持、且在应用候选范围内的完整生图模型名称。

SceneMeld 提供创作工作台，不提供 API、额度、账户或图片请求中转。服务价格、模型权限和可用性由你的服务提供商决定。使用参考图还需要服务支持图片编辑接口。

| 使用方式 | 如何进入 | 适用条件 |
| --- | --- | --- |
| Web | 打开上方 Web 链接 | 服务允许浏览器跨域访问（CORS） |
| 桌面版 | 在发布页面选择与你的系统和架构相符的安装包 | 请求由本机发送，不依赖浏览器 CORS |

桌面构建覆盖 Windows x64、macOS Intel、macOS Apple Silicon 和 Linux x64；具体可下载文件以发布页面为准。桌面版仍需要有效的网络、API Key 和模型权限。

## 2. 首次配置

![连接配置实际界面：API 基础地址、请求地址预览、API Key、生图模型和保存设置](./images/connection-fields.png)

*图 2：连接抽屉向下滚动后的实际界面。示例地址只用于说明格式；截图未填写密钥，因此「获取生图模型」仍不可用。*

1. 点击欢迎页的 **配置连接**，或工作区右上角的连接状态入口，打开 **连接配置**。
2. 向下滚动至 **API 基础地址** 和 **API Key**，填写服务商提供的信息。
3. 在 **生图模型** 中点击 **获取生图模型**，从当前渠道返回的受支持模型中选择。
4. 初次体验可取消勾选 **AI 规划适用场景** 中的所有选项，保留 **共用图片连接**，先完成基础生图。AI 辅助可以稍后配置。
5. 按需选择是否记住凭据，点击 **保存设置**。

### 基础地址怎么填

假设服务商给出的基础地址是：

```text
https://api.example.com/v1
```

这是示例地址，使用时请换成服务商实际提供的地址。应用会自动在其后追加图片接口路径，例如 `https://api.example.com/v1/images/generations`；不要把完整的 `/images/generations` 或 `/images/edits` 接口地址填入基础地址栏。是否包含 `/v1` 以服务商文档为准。

填写后检查界面中的实际请求地址和 **API Key 将发送至** 的主机名。正式使用要求 HTTPS，地址不能带用户名、密码、查询参数或 `#` 片段。

### 获取不到模型怎么办

点击 **获取不到目标模型？手动输入并确认**，输入应用候选列表中的完整模型 ID，点击 **确认使用**，再保存设置。此操作不验证渠道是否有调用权限，也不会试生成图片。

当前默认 ID 为 `gpt-image-2.5-flare`，候选还包含 `gpt-image-2` 等系列。应以当前界面候选和服务商权限为准，不能任意输入其他名称。带分辨率后缀的 ID 会原样发送；调整“质量”不会自动切换模型 ID。

**设置已保存或已配置不代表服务已经连通。** 完成一次实际生成才能确认该配置可用。

## 3. 生成第一张图片

![实际单图输入区：咖啡店提示词、单图模式、1比1比例、自动质量、发送箭头和本次操作摘要](./images/first-image.png)

*图 3：实际输入区。左下图片加号用于添加参考图，右侧蓝色向上箭头用于发送，最下方显示本次操作摘要。这里只展示发送前的状态。*

1. 首次进入时直接使用已有的 **新创作** 空白会话；已有创作内容时，可点击侧栏 **新建创作** 开始另一项任务。已有空白会话时该按钮可能不可用。
2. 在输入区将 **模式** 设为 **单图**，**比例** 选择正方形，**质量** 选择自动。
3. 输入下面的示例提示词。
4. 确认连接配置已保存后，点击输入框右侧蓝色向上箭头，或按 `Enter` 发送；输入多行文字时使用 `Shift + Enter`。
5. 等待生成完成，点击图片查看大图，再通过图片操作菜单下载作品。

```text
为一家街角咖啡店设计一张宣传图。
主体是一杯放在木桌上的热拿铁，旁边放一只牛角包。
清晨暖光从左侧窗户照入，奶油白和咖啡棕配色，真实摄影风格。
画面上方留出简洁的标题空间，暂时不要添加文字。
```

成功后会出现图片结果。若出现错误，先查看结果中的错误说明，再参考下方常见问题。

比例可选择自动、正方形、宽屏、竖屏、横向照片或纵向照片。自动比例由模型决定；其他比例也受目标服务实际支持情况影响。质量可选自动、低、中、高，具体耗时与计费以服务商为准。

发送前查看输入区的 **本次操作** 摘要。提示词中被识别出的模式、数量或规格指令可能覆盖本次选择，但不会修改默认设置。

生成过程中可以停止请求。停止本地等待不保证服务商同步取消处理或免除费用。

## 4. 使用参考图与继续修改

![上传参考图后的实际输入区：参考图1张、图标缩略图、添加按钮和修改要求](./images/reference-upload.png)

*图 4：使用项目自带 SceneMeld 图标演示上传，缩略图和「参考图 1 / 16」已出现。该图尚未提交生成。*

### 上传自己的图片

1. 点击输入框左下的图片加号（悬停提示 **添加参考图**），或将图片拖入、粘贴到输入区。
2. 确认参考图缩略图已出现，移除不需要的图片。
3. 描述哪些部分需要保留、哪些部分需要修改，然后发送。

若要复现截图，可下载[项目图标](../public/app-icon.png)，上传后输入「保留参考图中的 SceneMeld 图标主体与蓝色配色。将背景改为纯白，四周增加留白，不要添加文字。」

继续咖啡店示例时，换成自己的咖啡杯照片并输入：

```text
保留参考图中咖啡杯的形状与颜色。
将背景改成清晨的街角咖啡店，增加木质桌面和柔和窗光。
不要改变杯子的标志，画面上方保留标题空间。
```

支持 PNG、JPEG、WebP、GIF；最多 16 张，单张不超过 20 MB，总计不超过 50 MB。服务商可能有更严格的限制。带参考图的生成需要服务支持 `/images/edits`。

### 修改刚生成的作品

1. 对目标图片使用 **继续修改**。
2. 应用会把该生成结果作为参考图放入输入区，同时带回修订后的提示词或原提示词。
3. 将提示词调整为具体修改要求，例如“保留构图和杯子，把背景改成傍晚暖光，在顶部加入‘今日特调’”。
4. 检查参考图与文字，再发送。

“继续修改”不会立即发出请求。需要以某张结果为基础时，请确认该图已出现在参考图区域，不要只依赖会话中存在历史图片。

## 5. 重试与版本对比

想保持原来的要求、重新尝试当前图片时，使用 **按原设置重试此张**。想改变内容时，使用 **继续修改** 并调整提示词。

重试时上一版仍会显示。新版本生成完成后，可以切换 **上一版 / 新版本** 或 **并排对比**，然后选择 **保留上一版** 或 **采用新版本**。

完成选择后只保留其中一张，并且必须先完成选择才能再次重试。如果两版都想保留，请在取舍前分别下载。重试失败或停止重试时会保留上一版；重试会产生新的生成请求。

若出现“比例未匹配”提示，应用会保留已生成图片。可以先检查是否可用，再决定是否按原设置重试。

## 6. 多图与分镜

### 多图：一次尝试多个结果

![实际多图输入区：模式多图、数量4张和生成4张独立图片摘要](./images/batch-controls.png)

*图 5：选择「多图」后出现「数量」控件；截图选择 4 张，下方摘要同步显示 4 张独立图片。*

1. 将 **模式** 切换为 **多图**。
2. 选择数量（2–9 张），填写画面要求。
3. 确认本次操作摘要后发送，在结果网格中查看每张图片的状态。

多图生成的是相互独立的图片，不等同于连续故事。开启多图 AI 规划后，会先为整批规划差异化提示词。某张失败时，可针对该张重试，不必重新生成整批。

### 分镜：生成连续场景

![实际分镜输入区：咖啡店故事、分镜模式、4镜头和先规划后确认的摘要](./images/storyboard-controls.png)

*图 6：分镜模式的发送前状态。截图选择 4 个镜头；此时还没有进入方案确认或图片生成。*

1. 将 **模式** 切换为 **分镜**，选择自动或 3、4、6、9 个镜头。
2. 描述完整故事，例如：

```text
制作咖啡店开门营业的短片分镜：店主打开店门，研磨咖啡豆，
冲泡第一杯咖啡，顾客接过咖啡微笑。保持同一家店的暖色调与人物服装一致。
```

3. 发送后，在 **确认分镜方案** 中查看统一视觉设定，逐个检查并修改镜头标题与画面描述。
4. 点击 **开始生成 N 张分镜图** 后才开始请求图片；点击 **返回提示词** 可返回调整输入。

分镜 AI 规划默认开启，需要可用的 AI 辅助连接；关闭后使用内置模板。每个镜头生成一张图片，角色与场景一致性仍取决于模型结果，请逐张检查。

## 7. 可选的 AI 辅助

![连接配置顶部实际界面：AI规划适用场景、记住凭据、共用图片连接和独立AI连接](./images/connection-planning.png)

*图 7：连接抽屉顶部。单图、多图和分镜分别控制自动规划；截图显示默认仅勾选分镜。*

基础生图可不使用 AI 自动规划。需要规划或手动优化提示词时，再配置 **AI 辅助连接**：

1. 如果服务同时支持生图和对话，选择 **共用图片连接**；否则选择 **单独配置 AI 连接** 并填写对应 Endpoint 与 API Key。
2. 在 **AI 辅助模型** 中获取或手动填写该服务支持的对话模型名称。它与生图模型是不同的配置。
3. **推理程度** 初次使用保留自动；仅在服务支持 `response_format` 时开启 **结构化 JSON 输出**。
4. 勾选需要自动规划的场景，然后 **保存设置**。

| 场景 | 开启后的行为 |
| --- | --- |
| 单图生成 | 生图前规划一条完整提示词 |
| 多图生成 | 为整批规划不同的提示词 |
| 分镜生成 | 规划前后连续的镜头，供确认后生成 |

单图和多图自动规划默认关闭，分镜默认开启。推理程度只影响 AI 规划和提示词优化，不改变图片质量。AI 辅助会额外请求所配置的服务，可能产生额外费用。

### 手动优化提示词

输入文字后点击 **优化提示词**，对照原文检查优化结果；可以继续编辑结果，点击 **替换输入框** 应用，或点击 **保留原文** 放弃。优化结果不会自动发送，替换后仍需自行提交生成。

手动优化不受“AI 规划适用场景”勾选状态影响，但仍需有效的 AI 辅助连接。如果界面提示 **未通过安全复检**，该结果不能替换，应修改创作方向后再尝试。

## 8. 管理会话和作品

![实际本地数据抽屉：本地保存状态、会话与生成次数统计和清除创作记录按钮](./images/local-data.png)

*图 8：左侧底部「本地数据」打开的抽屉。截图仅查看记录状态，没有执行清除。*

- **会话**：通过侧栏“最近会话”切换项目；使用重命名操作把示例会话命名为“咖啡店宣传图”。窄屏可从顶部“打开会话列表”进入。
- **预览**：点击图片查看大图，并浏览同一会话中的图片。
- **复制与下载**：使用图片操作菜单。复制依赖浏览器或系统剪贴板权限；无法复制时可先下载。
- **删除会话**：会删除该会话的消息、参考图、生成图片和未发送内容，应用内无法撤销。
- **外观**：在工作区工具的“外观”中选择浅色、深色或跟随系统。
- **清除全部记录**：在“本地数据”中使用“清除创作记录”，会删除全部会话、消息与已保存图片，不影响连接配置。
- **清除连接配置**：在“连接配置”中执行，会保留创作记录；下次生成需重新填写连接信息。

删除或清理前，先下载需要保留的作品。生成期间部分会话操作不可用，可等待完成或停止生成后再操作。

## 9. 常见问题

| 现象 | 建议处理 |
| --- | --- |
| 提示基础地址无效 | 使用服务商的 HTTPS 基础地址；移除查询参数、片段和完整图片接口后缀，检查实际请求预览 |
| 401 或 403 | 核对密钥、有效期和模型权限；确认地址与密钥属于同一服务 |
| 404 或模型不存在 | 检查基础路径及完整模型 ID；获取模型列表，向服务商确认支持情况 |
| 获取模型列表失败 | 检查连接和权限；确认渠道支持目标模型后，可按应用候选范围手动输入并确认 |
| Web 提示网络错误或 CORS | 确认服务允许浏览器跨域；需允许 OPTIONS 预检、POST、Authorization 和 Content-Type。远程图片地址也需允许跨域读取；也可尝试桌面版 |
| 文生图成功，参考图失败 | 确认服务支持图片编辑接口，检查参考图类型、数量及大小 |
| 提示限流、额度不足或服务错误 | 查看服务商额度、限流和服务状态，稍后重试；不要连续重复提交 |
| AI 规划或提示词优化失败 | 检查 AI 辅助连接、对话模型和结构化输出兼容性；可关闭相应自动规划以使用基础生成 |
| 结果比例与选择不同 | 检查本次操作摘要和模型支持情况；保留可用结果，按需要重试 |
| 图片无法复制 | 检查剪贴板权限，关闭可能占用剪贴板的程序，或使用下载 |
| 图片无法读取或下载 | 本地文件可能已被清理，或远程地址已失效；现有记录不保证能恢复原图，必要时重新生成 |
| 重新打开后需要填密钥 | 未启用记住凭据时是预期行为；已启用时检查浏览器存储或系统凭据管理器是否可用 |
| 提示“当前仅临时保留”或保存失败 | 当前本地存储不可用，及时下载图片，避免关闭页面后丢失 |

排查或反馈时提供应用版本、使用方式（Web/桌面）、操作步骤及错误文案即可；截图中遮住 API Key 和不希望公开的内容。

## 10. 数据保存与隐私

会话、参考图和生成图片会在可用时保存到当前浏览器或桌面 WebView 的 IndexedDB。这里的“本地保存”不是云同步或永久备份；更换设备、浏览器、站点地址，或清理应用数据后，不应期待原记录自动出现。

API Key 默认仅在内存中保留。选择记住凭据后，Web 版使用当前浏览器的 localStorage，同源脚本和扩展可能读取；桌面版尝试使用系统凭据管理器，实际保护能力取决于系统与账户配置。

生成需要连接你配置的服务；启用 AI 辅助时也会向对应服务发送请求。服务商的数据留存、内容规则与费用由其决定。重要作品应另行下载保存。

更多说明见 [隐私说明](../PRIVACY.md) 和 [安全说明](../SECURITY.md)。开发与部署步骤见 [README](../README.zh-CN.md)。
